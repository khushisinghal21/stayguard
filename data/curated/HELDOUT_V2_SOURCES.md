# heldout_v2 sources

Built only from web sources and general knowledge of hotel-to-guest messaging. The detector's code, rules, lexicons, tests and earlier datasets were not consulted.
All domains, IBANs, phone numbers, handles, names and booking numbers in the rows are made up. Links on legitimate hosting (forms.gle, docs.google.com, drive.google.com, dropbox.com, bit.ly, tinyurl.com, cutt.ly, shorturl.at) use made-up IDs.
Most sources show the scam text only in screenshots or paraphrase it. Rows marked `reported_wording` reuse the fragments the sources quote. Rows marked `reported_pattern`, `multilingual` or `obfuscated` paraphrase or adapt a described pattern.
